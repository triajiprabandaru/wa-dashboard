📥 Update & Unggah Chat WhatsApp

Idempotent Loader

Pilih folder hasil ekspor obrolan WhatsApp dari komputer Anda. Sistem akan mendeteksi file teks chat dan file media pendukung secara otomatis.

📁
Klik untuk Memilih Folder Chat WhatsApp

          💡 Jalankan via Terminal (Untuk Upload Lengkap Media ke Drive)
          
        

        

          Upload media bergiga-byte langsung diproses dengan cepat & aman tanpa batas limit browser melalui perintah Python berikut:
        

        
python wa_parser.py "WhatsApp Chat dengan PROYEK" --out chat.jsonl
python wa_loader.py load chat.jsonl --project "AMG" --media-dir "WhatsApp Chat dengan PROYEK" --drive
